# cswatch Desktop Releases

Release artifacts for [cswatch-desktop](https://github.com/Dishairano/cswatch-desktop).

The Tauri updater points to:

```
https://github.com/Dishairano/cswatch-desktop-releases/releases/latest/download/latest.json
```

Publishing is automated by the `release.yml` workflow in the main repo when a `v*` tag is pushed.
